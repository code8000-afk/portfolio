WEB DESIGN : DATA VISUALIZATION

체계적인 분류와 차트로 완성한 기술수준평가 리포트

상단에 과학기술 지표 체계도를 배치해 세부 탐색을 돕고, 국가별 기술수준 및 격차 데이터를 막대그래프와 컬러 범례로 명확히 구성하여 직관적인 데이터 비교 분석 환경을 제공합니다.

SERVICE UI DETAILS

NTIS 분야별 주요 서브 서비스 UI

대용량 공공 데이터의 가독성을 극대화하고 탐색 효율성을 높이기 위해 최적화된 주요 서브 페이지 레이아웃입니다.

R&D 미션 현황 통합 대시보드

분야별 카테고리와 다각도 막대 차트를 활용하여 미션 현황을 시각화하고, 하단에는 웹 접근성 기준을 충족하는 데이터 테이블을 배치해 상세 과제 목록을 제공합니다.

정책·기술동향 정보 검색 UI

상단에 다중 검색 필터를 고정하고 조회 건수, 관리자 전용 다운로드, 엑셀 추출 등 유틸리티 기능을 체계적으로 정돈하여 방대한 입법·예결산 자료 탐색 효율을 높였습니다.
