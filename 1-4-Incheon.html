WEB DESIGN HOME

D-day 카운트다운 중심의,
직관적인 공모현황 대시보드 UI

메인 화면 좌측에 진행 중인 설계공모의 접수 기간과 D-day 잔여일을 대형 레드 뱃지로 강조하여 핵심 일정을 한눈에 파악할 수 있도록 구성했습니다. 우측에는 라이브 심사 중계(YouTube) 배너, 매뉴얼 다운로드, 공지사항을 배치하고, 하단에는 대표 당선작 조감도 슬라이드를 탑재하여 신뢰감 높은 공공 심사 platform 이미지를 연출했습니다.

WEB DESIGN NOTICE LIST

단계별 접수 일정을 한눈에,
정교한 공모현황 테이블 UI

참가등록부터 질의접수, 질의회신, 공모안 제출, 심사일까지 복잡한 전 진행 과정을 한 줄의 테이블 구조로 정돈했습니다. 상단 통합 검색 영역(연도, 공모명, 발주기관)을 통해 원하는 공모를 신속하게 찾을 수 있으며, D-day 뱃지 노출로 마감 임박 건을 즉시 인지할 수 있도록 설계했습니다.

WEB DESIGN ARCHIVING

당선작 3D 조감도 중심의,
시각적 카드형 아카이빙 갤러리

역대 교육시설 설계공모 당선작을 시각적으로 감상할 수 있는 갤러리형 아카이빙 페이지입니다. 건축 조감도 썸네일을 상단에 크게 배치하고, 하단에는 발주기관, 업체명, 참가등록 건수, 입상작 수 등 핵심 실적 데이터를 명확히 표기하여 고품질 건축 정보의 시독성을 극대화했습니다.

MOBILE DESIGN MOBILE

모든 디바이스 환경을 고려한,
유연하고 정교한 반응형 UI/UX

다양한 모바일 및 태블릿 해상도에서도 깨짐 없는 인터페이스를 제공합니다. 메인 대시보드의 D-day 현황 카드와 아카이빙의 그리드 레이아웃이 모바일 화면에 맞춰 1열 구조로 유연하게 재배치되며, 터치 친화적인 UI 요소를 적용하여 스마트폰 환경에서도 편리하게 공모 정보를 조회할 수 있습니다.

DETAIL ARCHIVING

공모 개요부터 심사평·도면까지, 원스톱 데이터 시각화 상세 UI

개별 공모의 종합 결과를 투명하게 제공하기 위한 원스톱 상세 조회 페이지입니다.
공모 개요부터 심사위원 명단, 종합 심사평, 당선작/입상작 3D 조감도 및 도면 데이터까지 체계적으로 정돈되어 있습니다.

FULL DATA SYSTEM

체계적인 데이터 분할 및 심사 결과 투명화 UI

상단 공모 개요 및 메타정보 표를 시작으로 심사위원 명단, 종합 심사평, 입상 결과, 당선작 배치도·배면도 및 3D 조감도 갤러리를 세로 스크롤 흐름으로 배치했습니다. 방대한 건축 정보와 심사 결과를 시각적으로 명확하게 구분하여 사용자가 원하는 데이터를 빠르게 탐색할 수 있도록 유저 경험을 최적화했습니다.
