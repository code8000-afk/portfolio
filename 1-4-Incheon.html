WEB DESIGN : HOME

D-day 카운트다운 중심 공모현황 대시보드 UI

진행 중인 설계공모의 접수 기간과 D-day 잔여일을 대형 뱃지로 강조하여 핵심 일정을 직관적으로 파악할 수 있게 설계했습니다. 하단에는 당선작 슬라이드를 탑재하여 신뢰감 높은 공공 심사 플랫폼 이미지를 연출했습니다.

WEB DESIGN : NOTICE LIST

단계별 접수 일정을 한눈에 보는 정교한 공모현황 테이블

참가등록부터 심사일까지 복잡한 전체 진행 과정을 한 줄의 테이블 구조로 정돈했습니다. 상단 통합 검색 영역과 D-day 뱃지 노출을 통해 사용자가 원하는 마감 임박 공모를 신속하게 인지하고 탐색할 수 있습니다.

WEB DESIGN : ARCHIVING

당선작 3D 조감도 중심의 카드형 아카이빙 갤러리

역대 교육시설 설계공모 당선작을 시각적으로 감상할 수 있는 갤러리 페이지입니다. 대형 건축 조감도 썸네일과 함께 발주기관, 업체명 등 핵심 실적 데이터를 명확히 표기하여 고품질 건축 정보의 시독성을 극대화했습니다.

MOBILE DESIGN

디바이스 환경을 고려한 유연한 반응형 UI/UX

다양한 모바일 해상도에서도 깨짐 없는 인터페이스를 제공합니다. 메인 대시보드의 D-day 카드와 아카이빙 그리드 레이아웃이 화면에 맞춰 1열 구조로 자연스럽게 재배치되어 스마트폰 환경에서도 편리하게 조회할 수 있습니다.

DETAIL ARCHIVING

공모 개요부터 도면까지 원스톱 데이터 시각화 상세 UI

개별 공모의 종합 결과를 투명하게 제공하는 원스톱 상세 조회 페이지입니다.
공모 개요, 심사평, 3D 조감도 및 도면 데이터 등을 체계적으로 정돈하여 방대한 건축 정보를 직관적으로 탐색할 수 있습니다.

FULL DATA SYSTEM

체계적인 데이터 분할 및 심사 결과 투명화

상단 공모 개요표를 시작으로 심사위원 명단, 종합 심사평, 입상 결과, 당선작 도면 갤러리를 세로 스크롤 흐름으로 배치했습니다. 방대한 건축 정보와 심사 결과를 시각적으로 명확하게 구분하여 사용자가 원하는 데이터를 빠르게 파악하도록 사용자 경험을 최적화했습니다.
