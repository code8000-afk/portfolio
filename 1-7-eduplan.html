WEB DESIGN : HOME

참가등록 및 공모안 제출 일정을 D-day 뱃지로 강조하여 탐색 편의성을 높였습니다. 3D 조감도 그리드 배치와 라이브 심사중계 배너를 통해 신뢰감 있는 공공 심사 플랫폼을 구현했습니다.

WEB DESIGN : ARCHIVING

당선작 3D 조감도 중심의 시각적 카드형 갤러리

WEB DESIGN : DETAIL PAGE

공모 개요부터 도면까지 원스톱 데이터 시각화

공모의 종합 결과를 한눈에 확인하는 상세 페이지입니다. 메타정보, 심사평, 입상 결과, 도면 다운로드 영역을 세로 스크롤 흐름으로 분할하여 방대한 데이터를 깔끔하게 시각화했습니다.

MOBILE DESIGN

디바이스 환경을 고려한 정교한 반응형 UI/UX

다양한 모바일 해상도에서도 쾌적하게 이용할 수 있도록 레이아웃을 고도화했습니다. 복잡한 일정과 조감도 카드를 1열 구조로 자연스럽게 재배치하여 모바일 탐색 편의성을 높였습니다.

DESIGN PROPOSAL

경기도교육청 에듀플랜 디자인 시안 제안

최종 채택안 외에 브랜드 방향성을 검토하기 위해 기획·제작되었던 디자인 컨셉 시안입니다.

CONCEPT A

매거진 스타일의 비주얼 대시보드 시안

신규 공모 건수와 소식을 상단에 강조하고, D-day 중심의 진행 공모와 롤링 슬라이드를 조합하여 매거진 형태의 세련된 비주얼을 연출한 시안입니다.

CONCEPT B

태그 검색 기반의 카드형 탐색 UI 시안

상단 해시태그 검색바와 공모 탭, 카드 그리드를 구조화하여 사용자가 관심 분야의 공모를 빠르고 직관적으로 탐색할 수 있도록 접근성을 강화했습니다.
