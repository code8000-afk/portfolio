WEB ACCESSIBILITY WA ACCREDITATION

웹 접근성 품질인증 마크 획득으로,
모든 사용자를 위한 보편적 사용성 완성

데이터바우처 웹사이트 리뉴얼 프로젝트 진행 시 한국 웹 콘텐츠 접근성 지침(KWAAG)을 철저히 준수하여 '웹 접근성 품질인증 마크(WA 마크)'를 공식 획득했습니다. 명도대비 확보, 시각 장애인을 위한 대체 텍스트 제공, 키보드 전용 접근성 보장 등 표준 기술을 완벽히 적용하여 고령자 및 장애인을 포함한 모든 사용자가 차별 없이 원활하게 데이터 서비스를 탐색하고 이용할 수 있도록 포용적 웹 환경을 구현했습니다.

WEB DESIGN HOME

데이터를 한눈에 빠르게 찾을 수 있도록,
통합 검색 상단 배치와 카테고리 노출

사용자가 목적에 맞는 데이터를 헤매지 않고 즉시 찾을 수 있도록, 메인 화면 최상단에 주요 검색 기능을 눈에 띄게 배치했습니다. 또한, 숨겨져 있던 상품별, 서비스별 카테고리를 직관적인 아이콘과 함께 전면에 모두 나열하여 탐색 동선을 최소화하고 웹 사용성을 크게 향상시켰습니다.

WEB DESIGN SUB PAGE

필터링 탐색 효율을 극대화하여,
맞춤형 데이터 검색과 정보 접근성 강화

검색 중심의 직관적인 상단 선택 탭을 도입하여 사용자가 원하는 조건의 다양한 콘텐츠를 빠르게 필터링하고 검색할 수 있도록 개선했습니다. 또한 불필요하게 여백을 차지하던 콘텐츠 영역을 최소화하고 화면 레이아웃을 효율적으로 재구성하여 한눈에 더 많은 데이터를 직관적으로 탐색할 수 있게 하였습니다.

MOBILE DESIGN MOBILE

다양한 모바일 해상도와 브라우저에서도,
끊김 없는 최적화된 반응형 UI/UX

스마트폰, 태블릿 등 기기별 해상도 차이와 다양한 모바일 브라우저 환경에 완벽히 대응하도록 모바일 레이아웃을 정교하게 설계했습니다. 좌측의 메인 화면과 우측의 서브 화면 모두 화면 크기에 맞게 핵심 정보가 자연스럽게 재배치되어, 어떠한 기기 접속 환경에서도 최상의 시독성과 편안한 탐색 경험을 선사합니다.
