WEB ACCESSIBILITY

한국형 웹 콘텐츠 접근성 지침(KWAAG)을 준수하여 'WA 마크'를 획득했습니다. 고령자 및 장애인 등 모든 사용자가 차별 없이 원활하게 데이터 서비스를 이용할 수 있는 포용적 웹 환경을 구현했습니다.

WEB DESIGN : HOME

통합 검색 상단 배치와 직관적인 카테고리 노출

사용자가 목적에 맞는 데이터를 즉시 찾을 수 있도록 주요 검색 기능을 메인 최상단에 배치하고, 숨겨져 있던 상품·서비스 카테고리를 아이콘과 함께 전면 노출하여 탐색 동선을 최소화했습니다.

WEB DESIGN : SUB PAGE

필터링 탐색 효율 극대화로 맞춤형 정보 접근성 강화

검색 중심의 선택 탭을 도입하고 불필요한 여백을 줄여, 사용자가 원하는 조건의 방대한 데이터를 한눈에 빠르고 직관적으로 필터링할 수 있도록 레이아웃을 전면 개편했습니다.

MOBILE DESIGN

모든 기기에 최적화된 끊김 없는 반응형 UI/UX

스마트폰, 태블릿 등 기기별 해상도와 다양한 브라우저 환경에 완벽히 대응합니다. 화면 크기에 맞춰 핵심 정보가 자연스럽게 재배치되어 최상의 시독성과 편안한 탐색 경험을 선사합니다.
