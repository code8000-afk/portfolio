WEB DESIGN : HOME

직관적인 카드형 정보 배치와 이용매뉴얼 Quick UI

주요 사업공고에 '접수중/접수예정' 상태 뱃지를 적용하여 핵심 과제를 한눈에 파악할 수 있습니다. 퀵 매뉴얼 바와 시스템 문의 콜센터를 전면에 배치하여 대시보드 중심의 사용성을 극대화했습니다.

WEB DESIGN : ONLINE SYSTEM

통합 검색과 4열 그리드 기반 온라인접수 대시보드

상단에 직관적인 검색바를 배치하고 하단에는 탭 필터링과 4열 카드 그리드를 적용했습니다. 공고 기간, 접수 상태, 원클릭 신청 버튼을 직관적으로 파악하도록 UI를 고도화했습니다.

WEB DESIGN : MY PAGE

진행 단계 시각화로 완성한 맞춤형 과제 수행 현황

수행 중인 과제 상태를 뱃지로 명확히 구분하고, 협약부터 종료까지의 진행 위치를 아이콘 프로그레스 바로 제공합니다. 주요 정보와 팝업조회 버튼을 빠르게 이용할 수 있도록 탐색 동선을 최적화했습니다.

MOBILE DESIGN

디바이스 환경을 고려한 유연한 반응형 UI/UX

다양한 모바일 해상도와 브라우저 환경에 완벽히 대응합니다. 마이페이지 과제 현황과 내부 프로세스 단계가 모바일에 최적화된 1열 구조로 자연스럽게 재배치되어 최상의 시독성을 제공합니다.

DESIGN PROPOSAL

과제관리시스템 내부 관리 UI 시안

업무 효율성과 데이터 시각화를 극대화하기 위해 설계된 내부 시스템 주요 화면 시안입니다.
(보안 정책 준수를 위해 화면 내 주요 데이터는 더미 데이터로 구성되었습니다.)

CONCEPT A

단계별 프로세스 및 이력 조회 중심 UI

본인확인부터 발급신청까지 4단계 스텝 배너로 진행 단계를 명확히 전달합니다. 조회된 과제수행실적 목록을 직관적인 데이터 테이블과 상태 태그로 구성하여 조회 편의성을 극대화했습니다.

CONCEPT B

문서 실시간 미리보기 및 발급 설정 분할 UI

발급될 증명서 레이아웃을 좌측에 실시간으로 보여주고, 우측에 용도 선택 및 출력 설정 패널을 분할 배치하여 출력 전 오류를 방지하고 발급 효율성을 대폭 향상시켰습니다.
