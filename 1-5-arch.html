WEB DESIGN : HOME

동적 비주얼 슬라이드와 D-day 중심 메인 대시보드

풀사이즈 당선작 조감도 슬라이드로 전문성을 강조하고, 메인 화면 중앙에 공고 접수 상태와 D-day 잔여일을 직관적으로 배치하여 건축사 및 출품자의 UX 탐색 편의성을 극대화했습니다.

WEB DESIGN : ARCHIVING

트렌디한 카드 레이아웃과 '찜하기' 개인화 기능 탑재

갤러리형 아카이빙 레이아웃으로 썸네일 중심의 트렌디한 그리드를 정돈했습니다. 고해상도 조감도 위로 '찜하기' 인터랙션 버튼을 제공하여 개인 맞춤형 공모 리스트 수집 기능을 지원합니다.

WEB DESIGN : DETAIL PAGE

공모 개요부터 도면까지 원스톱 데이터 시각화 아카이빙

메타정보 패널과 메인 조감도를 조화롭게 배치한 상세 페이지입니다. 탭 메뉴를 활용해 심사평, 당선작 도면, 입상작 조감도 갤러리 등 방대한 데이터를 깔끔하게 시각화하여 정보 접근성을 높였습니다.

MOBILE DESIGN

디바이스 환경을 고려한 정교한 반응형 UI/UX

복잡한 건축 정보와 당선작 갤러리를 모바일 세로 화면에 최적화된 1열 카드로 재배치했습니다. 터치 친화적인 UI 버튼과 높은 가독성의 타이포그래피를 적용하여 끊김 없는 탐색 경험을 선사합니다.

INTERNAL SYSTEM

건축설계공모 심사위원 신청현황 시스템 UI

단계별 탭 스텝을 배치하여 방대한 신청서 작성 과정을 직관적으로 안내합니다.
'임시저장' 기능을 비롯해 본인인증, 주소 검색 연동을 통해 사용자의 데이터 손실을 방지하고 편의성을 향상시켰습니다.
